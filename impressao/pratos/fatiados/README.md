# 🖨️ Pratos de Impressão Fatiados — Bambu Lab A1 (100% Filamento Preto)

Contém os 2 pratos `.3mf` prontos para enviar à Bambu Lab A1, configurados
exclusivamente para **Bambu PLA Basic Preto** (monocromático / slot único).
Fatiados com Bambu Studio 02.09.01.70 · `0.20mm Standard @BBL A1` · PLA ·
0.4 mm nozzle · Textured PEI Plate.

> Os pratos de projeto (sem gcode) ficam em `impressao/pratos/`.
>
> **Mudanças desta revisão:** peça **26 removida** (engrenagem), **04** com
> encaixe de 10 mm, **12** Turret V7 Redonda (86 mm) e as peças **H1/H2**
> incluídas no Prato 2.
