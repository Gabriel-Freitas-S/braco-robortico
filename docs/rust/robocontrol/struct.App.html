Expand description

Todo o estado da aplicação. Vive na thread da UI; a única concorrência é a thread leitora da serial dentro de Link.

Toma o controle do PC: #M + alvos iguais à pose atual, para o firmware adotar os alvos sem tranco.

pub(crate) fn stop(&mut self)

STOP: segura as juntas (#H), encerra replay/alvo manual e devolve o controle ao joystick.

Funciona também desconectado: só registra que não havia placa, para o usuário não achar que parou algo que estava rodando.

pub(crate) fn tick(&mut self, now: Instant)

Um passo do laço: leitura da serial, heartbeat de diagnóstico, gravação, replay e envio de alvos.

A ordem importa:

  1. Drena eventos. Erro de serial derruba o link e zera o estado de controle — nunca tentamos escrever num handle morto.
  2. Aplica mensagens: Text (banner/versão), Diag (limites/boots) e Status (pose, trava e quem está no controle — o firmware vence).
  3. Pede #B a cada 2 s, para detectar reinício da placa.
  4. Avança o replay ou o encerra (com loop opcional).
  5. Toque em qualquer pad cancela replay e alvo manual.
  6. Se o PC está no controle, envia #P (replay/alvo manual) ou #V (sticks) no máximo a cada TICK.

pub(crate) fn top_bar(&mut self, ui: &mut Ui, compacta: bool)

Monta a topbar. Em uma linha (telas largas) os três grupos ficam lado a lado; estreito, vira duas linhas com o STOP sempre visível à direita.

Os avisos de erro e de reinício são desenhados logo abaixo, fora dos grupos, porque precisam de largura total.

pub(crate) fn controle_bar(&mut self, ui: &mut Ui)

Grupo de controle: assumir/devolver o comando e travar/liberar a garra.

O estado exibido vem do firmware (pc/garra_travada), não do último clique; se a placa discordar, o botão acompanha a placa no próximo status.

pub(crate) fn seguranca_bar( &mut self, ui: &mut Ui, diagnostico: bool, gravando: bool, )

Grupo de segurança: STOP (sempre habilitado), indicador de quem controla e, em telas largas, o diagnóstico.

diagnostico só é true quando há espaço; com dois “Gravando” na tela (topbar e painel), a duplicata some no modo estreito.

pub(crate) fn reset_targets(&mut self)

Realinha os alvos com a última pose medida e centraliza os pads.

Chamado em toda troca de autoridade (assumir, devolver, STOP, queda da serial) para o app nunca continuar mirando um alvo antigo.

pub(crate) fn sticks( &mut self, ui: &mut Ui, altura_viewport: f32, centralizar: bool, )

Cabeçalho e pads. altura_viewport é medida antes do ScrollArea, para que a rolagem não confunda o cálculo do modo baixo com espaço infinito.

Os quatro controles são distribuídos como na bancada:

PadEixo XEixo Y
esquerdoBaseCotovelo
direitoGarraOmbro

centralizar (dock lateral) divide a sobra vertical; empilhado, o conteúdo flui de cima. Clicar num chip de ângulo devolve a junta em Option<usize> para abrir o modal.

pub(crate) fn recordings_panel(&mut self, ui: &mut Ui, compacta: bool)

Painel lateral de gravação (só no modo dock).

Um scroll só para o painel inteiro: qualquer estimativa de altura fixa cortava o bloco de replay quando havia movimento carregado.

Source

pub(crate) fn recordings_body(&mut self, ui: &mut Ui, compacta: bool)

Conteúdo do painel: gravar, replay e lista de movimentos salvos.

Gravar exige conexão (não há pose para capturar sem placa) e captura também o movimento feito pelo joystick — é “ensinar fazendo”. Reproduzir assume o controle do PC antes de iniciar. Excluir pede confirmação na própria linha e cancela o replay se o arquivo era o carregado.

Source

pub(crate) fn log_panel(&mut self, ui: &mut Ui)

Log recolhível com área de toque confortável.

Recolhido mostra só a última linha (com o texto encurtado pelo espaço); aberto vira um scroll de 110 pt que acompanha o fim.

Source

pub(crate) fn editor_angulo_modal(&mut self, ctx: &Context)

Modal para digitar o ângulo de uma junta.

Valida a cada frame com avaliar_alvo para mostrar o motivo do erro antes de confirmar. Enter ou “Mover” aplica; Esc ou “Cancelar” fecha. Confirmar assume o controle do PC se preciso e liga o alvo manual — o #P correspondente sai pelo Self::tick, no ritmo global.
